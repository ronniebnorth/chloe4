    probe).
  - They need a temporary hook
    `window.__chloe = { synthNote, … }   // TEMP level test` next to
    `window.__synthDrone`, deleted with `sed -i '/TEMP level test/d'`.
- **Vite** bundles the worklet with its imports through
  `import url from "./x.js?worker&url"`.
- **Worklet fetches don't appear** in `performance.getEntriesByType("resource")`
  or in CDP Network events. To confirm a load, use a temporary console line.
- **When removing TEMPDEBUG lines:** don't blind-`sed -i '/TEMPDEBUG/d'` if a
  tagged line is also real code (the duduk `.catch` was). Restore by hand.
- **Headless cleanup:** list PIDs with the `ps … | grep -E
  "remote-debugging-port=93[3]3|[v]ite preview"` pattern, kill them in a
  separate call, and confirm 0 remain.
