**Video journey** (`src/video.js`, `src/vad.js`, `src/voicetone.js`,
`?view=listen&jo=video`): idea from Ronnie's neighbor Tim (FB reel soundtracks).
- 60 frames → light + motion line (mix slider, invert); plays on the video's own clock.
- Cuts: 4×/s scan (color mix + gray picture), pinned by bisection; each cut gets
  a boom+shimmer hit (`cutHit`), biggest = gong; toggle "hit on cuts".
- Sound: decoded, played in its own AudioContext in step, saved with the music.
- Talking: Silero VAD (public/models/silero_vad.onnx, MIT) via onnxruntime-web
  (lazy-loaded, ~3.8 MB gz wasm); music ducks ~7 dB + 1.5 kHz dip; toggle.
- Voice tone: liveliness per 0.5 s (YIN pitch vs speaker median, pitch spread,
  loudness) → brightness ±0.15, note length; marks blue→orange; toggle.
- Save with music: MediaRecorder; Chrome = MP4 (H.264 + Opus on Linux), Firefox =
  WebM (canvas capture, Firefox has no video captureStream). Download link fallback.
  Recorder starts only after play() resolves (else Chrome gives no video track).
- Play/stop overlay on the video itself.
- Damaged frames: 4 s seek timeout, reopen past the bad spot.
- Friend-facing doc: Claude Doc "Chloe Scores Your Video"
  https://claude.ai/artifact/MGVtQSofuABoWC9HUHBiKY

Ronnie confirmed: saving works (Firefox WebM), the music dips when he talks.

## Next: the words (step 3 of the speech plan)

Ronnie's `transcribe --srt clip.mp4` (~/bin, whisper.cpp, local) leaves
`clip.<lang>.srt` and `clip.en.srt` (English translation) next to its output.
Plan: a "subtitles" drop/choose next to the video; parse SRT; each line → mood
(sad/tense darker, happy brighter) and chosen words → moments (e.g. "boom" → gong).
Nothing to install for anyone: Chloe only reads the .srt. Others need a
subtitle file from somewhere (CapCut/YouTube auto-captions export SRT); a later
option is Whisper in the browser (no install, but a ~40-150 MB model download).
Mood scoring must run locally (no sending his words to a service); a small
word-list in the browser is the obvious first try. Then: "try again" take button,
color → leaning, beats on cuts (see the Later list in the idea doc).

## How testing was done (scripts were in the session scratchpad; recreate)

- `npm run build`, then `npx vite preview --port 5199 --strictPort` (tests the real
  build, incl. the wasm). Headless Chrome: `google-chrome --headless=new
  --remote-debugging-port=9333 --user-data-dir=<scratch>/chrome-prof
  --autoplay-policy=no-user-gesture-required`; drive with a small CDP script under
  `node --experimental-websocket` (DOM.setFileInputFiles for the file input,
  Browser.setDownloadBehavior for saves). `window.__chloeVideo` exposes video state.
- Firefox: `firefox --headless --profile <scratch>/ffprof --no-remote
  --remote-debugging-port 9444` (WebDriver BiDi at ws://127.0.0.1:9444/session;
  input.setFiles; a user.js points downloads at scratch, never ~/Downloads).
- Ground truth: whisper-cli (small.en) timestamps; `ffmpeg select='gt(scene,0.3)'`.
- Gotchas: kill test processes by PID found with a bracketed grep
  (`[g]oogle/chrome`, `node_modules/.bin/[v]ite`) — a pattern that appears in
  your own command line kills your shell (exit 144). `rm` needs absolute paths.
  Audio tests play aloud: say "playing now" before.
- Ronnie pushes chloe4 himself (`! cd ~/rbn-projects/chloe4 && git push`); npm
  installs need his OK. Deploy = GitHub Action, ~40 s (`gh run watch`).
